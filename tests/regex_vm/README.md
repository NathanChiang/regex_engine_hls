# Regex VM checks

Run from the repository root with Vitis HLS/Vivado 2021.2 available. Generated
projects stay under `build/`; retained measurements stay under `results/`.
The implementation and performance limits are described in
[the optimization notes](../../hls/regexVM_new_optimization.md).

Use one standalone VM flow for C simulation, synthesis, and RTL co-simulation:

```powershell
$env:RE_VM_BENCH = 'diff'
$env:RE_VM_VARIANT = 'accel'
$env:RE_VM_PREDECODED = '1'
$env:RE_VM_ACTION = 'cosim' # csim or synth can also be selected
vitis_hls -f tests/regex_vm/run_hls_new_accel.tcl
python tests/regex_vm/summarize_vm_cosim.py regex_vm_new_accel_diff
```

`regex_vm_new_diff.cpp` checks 1,037 cases across generic bytecode families.
Its RTL DUT is the native predecoded core; the host testbench also compares
the narrow and packed-wide APIs. Run the three configuration-path C/RTL tests
with:

```powershell
vitis_hls -f tests/regex_vm/run_hls_config_tests.tcl
```

The existing 1,048-case compiler/Oniguruma corpus remains in `test.cpp`.
The host adapter runs it against the new VM or the original optimized VM:

```sh
VITIS_HLS_INCLUDE=/path/to/Vitis_HLS/2021.2/include bash tests/regex_vm/run_oniguruma_corpus.sh
VITIS_HLS_INCLUDE=/path/to/Vitis_HLS/2021.2/include bash tests/regex_vm/run_oniguruma_corpus.sh --baseline
```

For the 100-message reference fixture:

```powershell
$env:RE_VM_BENCH = 'apache'
$env:RE_VM_VARIANT = 'accel'
$env:RE_VM_PREDECODED = '1'
$env:RE_VM_ACTION = 'synth'
vitis_hls -f tests/regex_vm/run_hls_new_accel.tcl
python tests/regex_vm/run_new_accel_apache_rtl.py

$env:RE_VM_VARIANT = 'opt'
vitis_hls -f tests/regex_vm/run_hls_new_accel.tcl
python tests/regex_vm/run_opt_general_rtl.py
```

`fixtures/apache_100/` contains the input and capture vectors generated by
`host/test_cosim.cpp` from the log fixture. It is benchmark data only. Generic
validation does not depend on this expression. The generic original-VM bench
records two known synthetic possessive-loop mismatches without speedup ratios.

Complete-kernel synthesis and MMIO/AXIS verification use the scripts in
[`hls/`](../../hls/README.md). To reuse the same reference fixture, pass
`--lines 100 --vectors-dir tests/regex_vm/fixtures/apache_100` to
`hls/run_cosim.py`.
